# Campus3D GIS Feedback v0.7.2 BETA — Phase 4 同一点・同一経路・同一区域のA/B比較

## v0.7.1からの主な追加

- Phase 4パネルに **点／線／面のA/B数値比較** を追加。
- 点：地図をクリックすると、A・B・B−Aを表示。MRTはv0.7.1と同じpoint_id・XY・物理高さで厳密照合後、半径内の最近傍**同一**評価点を参照。
- 線：経路上の各サンプルで同じ厳密照合MRT点を参照。A（青）・B（橙）を**同じ温度軸**に重ねたグラフと距離代表値を表示。未被覆区間は欠測のまま。
- 面：同一区域に含まれる厳密照合MRT点のA/B平均・差、A/B高温点数比を表示。
- Surface Temperatureは**点**（GROUND/ROOFを同一XYで別々にパッチ交差判定）と**面**（同一区域に対する各モデル独立の水平投影面積加重平均）のA/B比較に対応。WALL、Surface線比較、Surface空間差分マップは未対応。各モデルのパッチ形状や被覆が異なり得るため、面平均の差は点ごとの差分ではありません。
- 比較結果をCSVとJSONレポートに保存。CSVには位置と座標系、解析日時、比較の種類、幾何WKT等を保存。元のGPKGは変更しません。

## インストール

QGIS 3.40以降 → プラグイン → プラグインの管理とインストール → ZIPからインストール。本ZIPは `campus3d_gis_feedback/` を含む形式です。前版の更新で反映しない場合はQGISを再起動してください。

## 実機試験（まずMRTの12時／18時を再利用）

1. 以前の `Campus3D_柏崎_04_surface.qgz` を開きます。
2. GIS FeedbackのPhase 4で、種類：**MRT**、A：`MRT_t013`（12:00）、B：`MRT_t019`（18:00）を選びます。すでに読み込まれていれば上部の読込操作は不要です。
3. Phase 4の**「同一点・同一経路・同一区域のA/B数値比較」**でモードを**点**にし、「地図で指定を開始」→MRT点の近くをクリック。A、B、差（B−A）が同じpoint_idで得られるか確かめます。複数クリック可。「操作終了」で通常の地図操作に戻ります。
4. モードを**線**に変更。「地図で指定を開始」→経路を2～5点クリック→「経路・区域を確定して比較」。AとBの折れ線が**共通縦軸**に表示されるか確認します。初期値は間隔10m、探索半径20m。
5. モードを**面**に変更。区域の頂点を3～5点クリックして確定。MRTの共通点数とA/B平均・Δを確認します。
6. 必要なら「A/B評価結果をCSV＋JSONで保存…」。選択した区域・経路は両方とも同じで、JSONにもWKT・対象ソースを保存します。

## 読み方と制約

- **ΔMRT = B − A**。負ならBのMRTが低いことを意味します。
- 12時 vs 18時の差は**時間変化**であり、材料変更・樹木追加の因果効果ではありません。同時刻でも気象条件や建物条件の一致は別途確認が必要です。
- MRTの点・線・面では、元の評価点の厳密照合による共通点に限ります。異なる格子の値を勝手に近傍同士で引き算しません。探索範囲内に共通点がない場合、値なしと示します。
- 線の代表値は離散サンプリング近似。歩行者が実際に受ける連続的な曝露量ではありません。
- MRT区域の平均は対応**点の単純平均**であり、面積加重平均ではありません。
- Surfaceの区域平均はGROUND／ROOFを別々に集計した**水平投影面積加重平均**。A/B間で被覆面積が異なる場合は差の解釈に注意してください。WALLは集計しません。
- 元のv0.7.1の共通スケール表示・ΔMRTマップ、およびPhase 2／Phase 3の既存機能は維持。Deltaマップ生成と今回の空間数値比較は独立して使えます。
- 本版は**オフライン検証のみ**完了。QGIS 3.44での実際の作図、レイヤ読み込み、エクスポートは実機で確認してください。
